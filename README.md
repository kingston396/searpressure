# Sear Pressure

A cooking game about running a food truck: swap between chefs, chop, cook and plate against the clock, fight
fires, win over the Judge, and drive the truck from stop to stop.

- **`OrderUp/`**: the original web version, a single `index.html` you can open in a browser.
- **`SearPressureUnity/`**: the Unity 6 port (Unity 6000.3.9f1). See `SearPressureUnity/README.md` for how to
  open it, run the headless tests and deploy the online relay server.
- **`store/`**: everything for Google Play and the App Store. **Start with `store/RELEASE-TODAY.md`** (Unity → Android Studio → Play). Also: listing text (`listing.md`), privacy policy,
  icons, feature graphic and screenshots.
